# 第四阶段测试报告

## 实现范围

- `observation_records` 数据表与 `0004_create_observation_records` 增量迁移
- 6 个观察维度、12 个中性项目、5 种可区分选项
- 观察记录增删改查、儿童历史、日期筛选和分页
- 同一儿童视频分析记录的可选关联，允许关联失败记录但不展示虚假分析结果
- 基于实际填写内容的确定性摘要和数据完整性统计
- 正式 Vue 行为观察页面，以及儿童档案、观察记录、视频详情之间的导航

## 安全与边界

- 所有定义和业务接口均复用管理员认证。
- 后端验证儿童、视频存在性和归属关系，不能跨儿童关联视频。
- “本次未观察到”“无法判断”“未观察”和未填写保持不同含义。
- 不调用外部大模型，不生成自闭症概率、风险等级、严重程度或治疗效果。
- 删除视频分析记录时，观察记录保留且可选外键置空；删除儿童档案时级联删除其观察记录。

## 实际测试

- 后端完整回归：32 项通过，包含前三阶段原有 22 项与第四阶段新增 10 项。
- TypeScript 独立类型检查：通过。
- Vite 生产构建：通过；观察页面独立懒加载分块约 12.99 kB（gzip 约 4.95 kB）。
- 数据库检查：`0002`、`0003`、`0004` 均实际应用，基础表完整。
- 现有本地数据库迁移后仍保留原管理员记录（1 条）；迁移未删除或重建前三阶段数据。
- 真实 HTTP 联调：管理员会话、儿童建档、观察创建、列表、儿童历史、更新、删除均通过；动态摘要按填写内容变化；未登录访问返回 401；`/observations` 前端路由返回 200。

覆盖范围包括：创建、详情、编辑、删除、儿童历史、分页、日期校验、观察枚举校验、不存在儿童、跨儿童视频、失败视频关联、鉴权、持久化、动态摘要、缺失状态区分和迁移幂等性。Starlette 测试客户端需要本地 `socketpair`，因此完整 pytest 在正常本机权限下执行；受限沙箱本身会阻止该本地套接字。

## 已知限制

- 当前没有真实浏览器自动化环境；前端通过 TypeScript 检查、Vite 构建和实际 HTTP 接口联调验证。
- 观察摘要为透明、确定性的文本整理规则，不是自然语言模型或医学判断。
- 本阶段不比较不同日期记录的“改善/恶化”，只保留原始记录供人工查看。
