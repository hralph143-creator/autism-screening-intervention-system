# 最终系统测试与验收报告

验收日期：2026-10-26  
项目：基于深度学习的自闭症筛查与干预系统  
版本：1.0.0  
最终提交：`feat: complete stage six reports and final integration`（以 Git 日志中的当前提交哈希为准）

## 1. 总体完成情况

第一至第六阶段主体功能已完成。系统在 Windows 本机运行，使用单管理员会话、匿名化儿童档案、真实 MediaPipe 通用视觉模型、本地 SQLite 数据库和本地文件存储。第六阶段新增综合历史、真实数据统计、报告数据聚合、A4 报告预览及浏览器打印/保存 PDF。

系统定位保持为教学科研与日常行为辅助观察工具，不提供自闭症诊断、医学风险评分、病情严重程度、疗效判断或自动治疗建议。

## 2. 第一至第六阶段功能汇总

1. 第一阶段：FastAPI、Vue 3、TypeScript、SQLite、管理员初始化/登录、Windows 脚本与基础布局。
2. 第二阶段：匿名化儿童档案创建、查询、编辑、删除、搜索、分页及首页统计。
3. 第三阶段：MP4 严格校验、后台任务、真实 Pose/Face Landmarker 推理、覆盖率、运动统计、结果帧、趋势图和安全文件访问。
4. 第四阶段：六维度中性行为观察、明确区分五类观察状态、视频关联、确定性摘要及数据完整度。
5. 第五阶段：12 项内置家庭互动活动、资源维护、儿童活动记录、内容快照和真实分类统计。
6. 第六阶段：儿童综合概览、统一时间线、筛选/排序/分页、跨模块详情跳转、综合报告数据、A4 预览、打印和保存 PDF。

此外完成了短视频自适应采样、上传控件状态同步、侧栏语义图标和系统品牌图标优化。

## 3. 实际技术架构

- 前端：Vue 3.5、TypeScript 5.7、Vite 6、Element Plus 2.9、ECharts 6。

- 视频：OpenCV 4.12、MediaPipe 0.10.32、CPU 单工作线程。
- 部署：Windows `setup.bat / run.bat / check.bat`，端口 8001/5173。

## 5. API 接口汇总

现有接口覆盖认证、系统信息、儿童档案、首页统计、视频分析、行为观察、活动资源和活动记录。第六阶段新增：

- `GET /api/children/{child_id}/overview`：档案信息、三类记录数量、最近日期、月度记录计数、视频状态和活动分类计数。
- `GET /api/children/{child_id}/timeline`：按类型、日期、顺序和页码查询摘要时间线。
- `GET /api/children/{child_id}/report`：按日期范围和选定类型生成实时报告数据。

以上接口均要求管理员登录。时间线不返回视频结果数组、原始视频或本机文件路径；报告最多纳入 200 条记录。

## 9. 综合历史与报告

综合时间线按业务日期排序：视频明确使用任务创建日期，观察使用观察日期，活动使用实际活动日期；相同日期继续按创建时间、类型和记录 ID 稳定排序。删除源记录后时间线实时更新。

报告只整理所选儿童和日期范围中的真实记录。完成视频才返回实际指标；失败任务不生成虚假覆盖率。观察状态保持原值，活动使用创建记录时保存的活动快照。用户备注由 Vue 文本插值转义，不使用 `v-html`。

报告按钮调用浏览器打印对话框，用户可选择打印机或“保存为 PDF”；系统不宣称服务端已自动生成文件，也不在浏览器长期保存报告副本。

## 13. 数据安全与权限检查

- 综合历史和报告匿名访问均返回 401。
- 查询均强制使用指定 `child_id`，自动化测试验证儿童数据隔离。
- 报告 URL 只传儿童 ID、日期和类型，不传备注或完整记录。
- 视频文件没有公开静态目录；结果帧按任务和白名单文件名鉴权读取。
- 时间线和报告不返回 `file_path`、`stored_filename` 或 Cookie。
- 报告中的失败原因使用通用提示，避免暴露内部异常路径。
- 测试流程使用临时数据库，结束后自动清理，不污染正式数据。
- 系统不调用第三方 AI API，不上传儿童业务数据。

## 14. 已知限制与未完成的人工验证

- 浏览器/操作系统打印对话框无法由本次自动化可靠控制，需人工确认具体打印机驱动下的分页效果。
- 当前后台任务队列为进程内单线程，适合单机轻量使用，不适合多机并发部署。
- SQLite 适合本地单管理员场景，不提供复杂多用户权限。
- 视频检测受画面角度、光线、遮挡、主体大小和多人画面影响。
- 大型前端公共分块仍有 Vite 非阻断告警。

## 15. 系统功能边界

系统没有训练或部署自闭症分类模型，未进行临床敏感度/特异度验证。姿态覆盖率、面部覆盖率、运动量、观察频次和活动记录次数均不能直接解释为自闭症风险、病情程度、康复变化或治疗效果。家庭活动只作为一般互动参考。
