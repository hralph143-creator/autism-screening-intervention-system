- Pose：官方 `pose_landmarker_lite.task`，5,777,746 字节
- Face：官方 `face_landmarker.task`，3,758,596 字节
- 运行库：MediaPipe 0.10.32，CPU XNNPACK，VIDEO mode
- 两个模型均通过真实创建与关闭，不以“文件存在”代替可用性判断
- Windows 中文项目路径下，模型采用字节缓冲传入 MediaPipe，规避原生层无法打开 Unicode 路径的问题

使用 TensorFlow 官方测试数据中的成人深蹲 MP4 做直接推理：

- 视频：720×1280、5 FPS、13 秒
- 约 2 FPS 采样：33 帧
- Pose 有效：33/33（100%）
- Face 有效：0/33（主体脸部条件不满足，按缺失保留）
- 生成结果帧：5 张
- 头部位置变化与上肢运动变化均生成有效统计
- 直接推理约 1.2 秒；含临时数据库、上传、队列轮询和 5 张结果帧鉴权读取的完整 API 链路约 2.3 秒（本次测试机器，仅作运行证明，不作性能承诺）

另使用 MediaPipe 官方 `portrait.jpg` 在 `VIDEO` 模式执行 Face Landmarker，实际检测到 1 张面部和 478 个面部关键点。
